# AI-Based Personal Finance Advisor

## Overview

The AI-Based Personal Finance Advisor is a web-based application that leverages artificial intelligence to provide personalized financial advice. Built using Streamlit, this tool allows users to input their financial information, such as income, expenses, savings, and goals, to generate tailored advice and recommendations. The system uses Groq's LLaMA 3 (8B) model to process user inputs, generate insights, and optimize financial decisions in real-time.

## Features

- **Personalized Financial Advice**: Automatically generates financial advice based on user-provided data (e.g., income, savings, goals).
- **Code Optimization & Generation**: The system offers code generation for users with specific finance-related programming needs, optimized by Groq's AI model.
- **Interactive Chatbot**: An AI-driven chatbot to answer queries related to financial concepts and assist users in understanding their data.
- **Real-Time Data Processing**: Immediate processing of user input with real-time results presented in an easy-to-understand format.
- **Optimized Code Download**: Ability to download generated code in Python or Jupyter Notebook formats for further use and learning.

## Technologies Used

- **Frontend**: Streamlit for a simple, responsive, and interactive user interface.
- **Backend**: Groq's LLaMA 3 (8B) model via Groq API for AI-driven financial advice and optimization.
- **Docker**: Containerization of the app for consistent performance across various environments.
- **Python**: The main programming language used for implementing the logic and algorithms.
